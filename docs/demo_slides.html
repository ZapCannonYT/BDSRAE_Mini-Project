Detectors on injected drift: ADWIN 26.5 h median delay, Page-Hinkley (strict) 17 h

City-wide drift, 8 seeds. ADWIN: 4.4 false alarms per 1000 h. Page-Hinkley: 2.3. PSI is not comparable: its summer reference fired on seasonal change before the drift began.

Fairness: a city-wide detector misses drift in one borough

Brooklyn-only drift: the city-wide ADWIN caught 25%, Brooklyn's own detector caught 100%. So we monitor per borough.

Drift does not hit boroughs equally, and retraining can make it worse

Crash error: Manhattan 11.8% to 24.6%, Queens 21.8% to 52.5%. Retraining sent Staten Island far higher, because the go-live check looks only at city-wide error.

Retraining policy: a one-hour-ahead model barely benefits

Crash error: never retrain 28.9%, monthly 36.3%, best drift-triggered 28.6% (58 retrains). Recommendation: alarm per borough, and add a per-borough check before a new model goes live. Every decision is written to an audit log.
